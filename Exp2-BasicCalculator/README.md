## How to Run

1. Open the `Exp2-BasicCalculator` project folder.
2. Locate the Java source file containing `main()`.
3. Compile it, for example:

   ```bash
   javac Calculator.java
   ```

4. Run it, for example:

   ```bash
   java Calculator
   ```

Replace `Calculator.java` and `Calculator` with the actual source filename and class name.
