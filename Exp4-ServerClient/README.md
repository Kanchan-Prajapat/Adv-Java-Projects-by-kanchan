# Server-Client Communication

A Java project for learning communication between a server and a client.

## Overview

The project explores a server-client model in which a server waits for a client connection and the client connects to the server. The exact protocol and message flow depend on the implementation.

## Concepts

- Server and client roles
- Connection setup
- Sending and receiving data
- Network ports and connection errors

> Keep only the concepts that are implemented in this project's source code.

## Technologies

- Java
- Java networking APIs, if used by the implementation

## Prerequisites

- A compatible JDK
- An IDE or terminal

## How to Run

1. Open the `Exp4-ServerClient` folder.
2. Identify the server and client classes.
3. Compile the Java files according to your source structure.
4. Start the server first.
5. Start the client in a separate terminal.
6. Use the host and port configured in the code.

Example commands (replace filenames and class names with the actual ones):

```bash
javac Server.java Client.java
java Server
```

In another terminal:

```bash
java Client
```

## Troubleshooting

- Confirm that the server is running before starting the client.
- Check that both sides use the same host and port.
- Make sure the port is not already in use.
